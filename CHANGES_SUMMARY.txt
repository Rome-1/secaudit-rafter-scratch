OVERVIEW:
This implementation addresses the system metrics not being written on start and
improves the authentication system's handling of Bearer tokens.

================================================================================
FILES MODIFIED:
================================================================================

1. /app/conf/configuration.go
   - Added Password field to prometheusOptions struct

2. /app/consts/consts.go
   - Added PrometheusDefaultPath constant ("/metrics")
   - Added PrometheusAuthUser constant ("prometheus")

3. /app/core/metrics/prometheus.go
   - NEW: Metrics interface with methods:
     * WriteInitialMetrics(ctx context.Context)
     * WriteAfterScanMetrics(ctx context.Context, success bool)
     * GetHandler() http.Handler
   - NEW: metrics struct implementing Metrics interface
   - NEW: NewPrometheusInstance function for dependency injection
   - Enhanced WriteInitialMetrics to record DB metrics on startup
   - Enhanced GetHandler to apply BasicAuth when password is configured

4. /app/server/auth.go
   - NEW: tokenFromHeader function for proper Bearer token extraction
     * Case-insensitive "Bearer" prefix check
     * Proper token extraction and validation
     * Returns empty string for malformed/missing tokens
   - Modified jwtVerifier to use tokenFromHeader
   - Kept authHeaderMapper for backward compatibility (deprecated)

5. /app/server/server.go
   - Removed authHeaderMapper from middleware chain
   - JWT verification now handled by tokenFromHeader

6. /app/scanner/scanner.go
   - Added metrics field to scanner struct
   - Updated GetInstance to initialize metrics interface
   - Updated RescanAll to use metrics interface methods

7. /app/cmd/root.go
   - Modified startServer to create Metrics instance
   - Call WriteInitialMetrics on application startup
   - Use GetHandler() for Prometheus endpoint with BasicAuth support
   - Removed unused promhttp import

8. /app/cmd/wire_injectors.go
   - Added CreatePrometheusMetrics wire injector

9. /app/cmd/wire_gen.go
   - Regenerated with new dependency injectors
